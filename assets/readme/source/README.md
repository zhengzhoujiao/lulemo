# README 顶图源文件

发布文件：[`../hero.webp`](../hero.webp)，2400 × 960，供 GitHub 以全宽展示。

- `hero-layout.svg`：1200 × 480 的可编辑排版，包含标题、文案、打卡日历与抛币元素；引用同目录的 `hero-subject.png`。
- `hero-subject.png`：通过内置 ImageGen 编辑的透明背景卡通简笔成年男性插画，使用粗线条、简化五官与平面色块，保留原始 alpha 通道。
- `hero-prompt.txt`：实际使用的完整生图提示词。

SVG 是合成源文件。用浏览器直接打开它可查看完整排版；README 引用已合成的 WebP，避免嵌套图片在 GitHub SVG 渲染中缺失。修改标题或人物后，以 1200 × 480 画布、2 倍像素密度重新渲染，再导出 WebP。

## 内容与视觉方向

受众：希望记录个人习惯、以轻松方式进行自我管理的成年男性。

一句话价值：记录日常，找回自己的节奏。

主要证据：`doc/img/part1.png` → `part2.png` → `part3.png`，按个人记录、社区陪伴、身份与反馈展开。

第一次成功操作：注册账号 → 选择身份 → 完成打卡。

视觉主题：使用手机记录日常的卡通人物，搭配打卡日历与趣味硬币。人物为概念插画，真实功能由正文中的产品截图展示。

配色：淡紫底色 `#f1eef9`、深紫文字 `#29213c`、紫色辅助 `#d1c4ed`、打卡绿 `#16a34a`、硬币金 `#f8e6b4`，衔接现有截图的紫色背景与界面用色。

字体：Microsoft YaHei / Segoe UI / PingFang SC / sans-serif。渲染时加载常规与粗体字重，保持中文标题的粗细层级。圆角 28，主体留白 64；正文、命令与链接保留为 Markdown，方便搜索与维护。
